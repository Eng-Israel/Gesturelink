Gesturelink portable Windows app

1. Extract or copy the complete Gesturelink folder to a location you can write to.
2. Double-click Gesturelink.exe.
3. Keep its console window open while using the app. Close it with Enter when finished.

The app opens in your default browser and includes its Python runtime, trained
20-sign model, hand-landmark detector, and sign-video library. Python and pip
downloads are not needed. Camera access works on this computer through localhost.

An installed browser is required. Speech voice availability depends on Windows
and browser speech settings. Internet access is used only for optional web fonts
and external conference connectivity; the local app and sign recognition run
on this computer.

The portable folder is about 0.8 GB because it includes the full sign-video
collection. The WLASL videos are restricted to academic/computational use under
their dataset terms; keep the bundle and its use within those terms.
Copy the entire folder when sharing it; do not move Gesturelink.exe by itself.
